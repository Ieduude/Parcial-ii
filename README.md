## Descripción

El proyecto consiste en un sistema de gestión para un estacionamiento que permite registrar automóviles y motocicletas, calcular el costo según las horas utilizadas y aplicar un descuento del 10% cuando se superan las cinco horas.

El programa utiliza programación orientada a objetos, herencia, abstracción y polimorfismo, además de colecciones como ArrayList, HashSet y HashMap. También incluye validaciones y manejo de excepciones.

## Funciones principales

- Registrar vehículos.
- Mostrar todos los vehículos registrados.
- Buscar vehículos por placa.
- Mostrar el vehículo con mayor costo.
- Mostrar el total general recaudado.
- Mostrar el total recaudado por tipo de vehículo.
- Validar placas duplicadas.
- Validar datos ingresados.
- Manejar errores de entrada mediante excepciones.
